#  3.5% OTM PE Options Backtester

A Python backtesting tool for evaluating 3.5% Out-of-The-Money Put (PE) option strategies using historical data.

##  Features
- Backtests 3.5% OTM PE option strategy  
- Calculates trade-wise P&L and equity curve  
- Supports custom entry/exit logic  
- Generates performance metrics (win rate, drawdown, returns)

##  Structure
- data/          Historical data  
- engine/        Backtesting engine  
- strategies/    Strategy logic  
- results/       Output reports  
- main.py        Run backtest  

##  Usage
pip install mathlib, panda, numpy
python main.py
